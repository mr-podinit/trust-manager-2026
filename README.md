# Trust Manager – local configuration

## `kyverno/mount-ca-certificates.yaml`

This file contains four **Kyverno `MutatingPolicy`** resources that automatically inject CA certificates generated by **trust-manager** into Pods, based on annotations on the Pod itself.

All policies:

- use `apiVersion: policies.kyverno.io/v1` and `kind: MutatingPolicy`;
- act on `pods` resources (`core/v1`) during `CREATE` and `UPDATE`;
- disable autogen for Pod controllers (`autogen.podControllers.controllers: []`), so no rules are generated for Deployments/ReplicaSets;
- use `patchType: ApplyConfiguration` to add volumes and `volumeMounts`;
- read the mount path from a Pod annotation and mount the `my-ca` `ConfigMap`;
- avoid re-applying the mount if a volume with the expected name already exists.

### Included policies

#### 1. `trust-manager-mount-jks`

- **Annotation**: `trust-manager.io/mount-jks`
- **Added volume**: `ca-bundle-jks`
- **ConfigMap**: `my-ca`
- **Mounted subfile**: `cacerts`
- **Effect**: mounts the Java JKS truststore inside every container of the Pod, read-only, at the path specified by the annotation.
- **Exclusion condition**: does not apply the mutation if a volume named `ca-bundle-jks` already exists.

#### 2. `trust-manager-mount-pem`

- **Annotation**: `trust-manager.io/mount-pem`
- **Added volume**: `ca-bundle-pem`
- **ConfigMap**: `my-ca`
- **Mounted subfile**: `ca-certificates.crt`
- **Effect**: mounts the system PEM bundle inside every container of the Pod, read-only, at the path specified by the annotation.
- **Exclusion condition**: does not apply the mutation if a volume named `ca-bundle-pem` already exists.

#### 3. `trust-manager-mount-p12`

- **Annotation**: `trust-manager.io/mount-p12`
- **Added volume**: `ca-bundle-p12`
- **ConfigMap**: `my-ca`
- **Mounted subfile**: `bundle.p12`
- **Effect**: mounts the PKCS#12 bundle read-only at the path specified by the annotation.
- **Exclusion condition**: does not apply the mutation if a volume named `ca-bundle-p12` already exists.

#### 4. `trust-manager-mount-all`

- **Annotation**: `trust-manager.io/mount-all`
- **Added volume**: `ca-bundle-all`
- **ConfigMap**: `my-ca`
- **Effect**: mounts the entire `my-ca` `ConfigMap` read-only at the path specified by the annotation, without using `subPath`.
- **Exclusion condition**: does not apply the mutation if a volume named `ca-bundle-all` already exists.

### Usage example

```yaml
metadata:
  annotations:
    trust-manager.io/mount-jks: /opt/java/openjdk/lib/security/cacerts
    trust-manager.io/mount-pem: /etc/ssl/certs/ca-certificates.crt
```

With these annotations, the `trust-manager-mount-jks` and `trust-manager-mount-pem` policies mount `cacerts` and `ca-certificates.crt` respectively into the Pod's containers.

### Application

```bash
kubectl apply -f kyverno/mount-ca-certificates.yaml
```
